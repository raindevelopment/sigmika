# Security Policy

## Supported Versions

Currently supported versions of the Sigmika Language are:

| Version.     | Supported          |
| ------------ | ------------------ |
| dev_branch   | :white_check_mark: |

## Reporting a Vulnerability

Please report bugs, vulnerabilities in the Core libraries and the language itself in the Issues tab on GitHub.

Use a report template and specify your hardware specs, used OS or underlying framework.
